# my-drive

Arquivo pessoal de documentos e relatórios, publicados como páginas estáticas via GitHub Pages.

## Conteúdo

### `jornada-games/`

Auditoria de produto e usabilidade do [Jornada Games](https://www.jornadagames.com/) —
marketplace brasileiro de card games, em beta — conduzida em 30 de agosto de 2026.

| Arquivo | Descrição |
|---|---|
| `index.html` | O relatório completo. Abre direto no navegador, sem servidor. |
| `screenshots/*.png` | 48 capturas em resolução cheia, nomeadas por tela e fluxo. |
| `screenshots/web/*.jpg` | As mesmas em JPEG otimizado — é o que o relatório carrega. |
| `notas/achados.md` | Dados brutos da investigação, incluindo o registro das correções feitas durante a apuração. |

O relatório cobre a experiência do comprador (~75%) e a do vendedor (~25%), com 18 problemas
documentados no formato *problema → evidência → impacto → hipótese de solução*, seguidos de
uma priorização e de oportunidades de diferenciação.

Nenhuma compra foi finalizada e nenhum cadastro de vendedor foi enviado durante a apuração.
